# Day 16 — Polbudandsonltd

Frontend-only renovation business concept for the 100 Days Local Business Website Challenge.

## Structure
- index.html — landing page
- style.css — responsive styles and visual panels
- script.js — navigation, scroll reveals and demo-only form notice

## Notes
This is an independent, unofficial website concept. The business has not approved the design. The contact form does not send or store submissions; use the listed phone or email to contact the business. Visual panels are illustrative CSS designs, not photographs of completed customer projects. Google Fonts requires an internet connection.

Built for GitHub Pages at the repository root.
